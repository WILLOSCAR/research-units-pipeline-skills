# Triage Labels

The engineering skills use five canonical triage roles. This repository adopts the label vocabulary from `mattpocock/skills` verbatim, so the string stored by the private local-markdown tracker under `.scratch/` is the label itself.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | Will not be actioned |

Store the label in a `Status:` line near the top of each local issue file.
